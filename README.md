🚀 Shivam Prakash | Portfolio

A modern, interactive personal portfolio website showcasing frontend development and data analytics skills. Built with **HTML5**, **CSS3**, and **JavaScript** with stunning animations and responsive design.

📌 Overview

This portfolio is a fully responsive, single-page application that highlights:
- **Frontend Development** expertise with modern web technologies
- **Data Analytics** capabilities and visualizations
- **Academic Background** in Master of Computer Applications (MCA)
- **Technical Skills** across multiple domains
- **Featured Projects** demonstrating practical experience

🎬 Key JavaScript Features

# Animations & Effects
- **Preloader**: Displays custom loader for 1.2 seconds on page load
- **Scroll Reveal**: Elements fade in and slide up as they enter viewport
- **Skill Animations**: Progress bars animate when visible
- **Particle System**: 80 animated particles float across the background
- **Hero Parallax**: Image moves based on mouse position
- **Project Card Tilt**: 3D perspective effect on hover

# Navigation
- **Mobile Menu Toggle**: Hamburger menu for mobile devices
- **Active Link Highlighting**: Navigation links highlight based on scroll position
- **Smooth Scroll Behavior**: Seamless navigation between sections

# User Experience
- **Back to Top Button**: Appears after 500px scroll, smooth scroll to top
- **Dynamic Footer**: Year automatically updates
- **Responsive Typography**: Scales for different screen sizes

🚀 Getting Started

# View Live
The portfolio is configured for GitHub Pages. Access it at:
```
https://shivam11191.github.io/portfolio/
```

# Local Development
1. Clone the repository:
```bash
git clone https://github.com/shivam11191/portfolio.git
```

2. Navigate to the directory:
```bash
cd portfolio
```

3. Open `index.html` in your browser or use a local server:
```bash
python -m http.server 8000
# or
npx http-server
```

🔧 Customization

# Update Personal Information
Edit `index.html` to update:
- Name and title
- About section content
- Contact information
- Project descriptions
- Skills and proficiency levels

# Modify Styling
Edit `style.css` to change:
- Colors (CSS variables in `:root`)
- Animations timing
- Layout and spacing
- Font sizes and styles

# Add Interactivity
Edit `script.js` to:
- Modify animation triggers
- Add new interactive features
- Customize typing effect words
- Adjust skill proficiency percentages
